Timed Session Plan (4 Hours)

09:00 – 10:00 — Intro & Packet Anatomy

Topics: TCP/IP layers, headers vs payloads, common protocols (HTTP, DNS, Modbus), and why packet context matters.

10:00 – 11:00 — Wireshark Deep Dive

Hands-on: Install/configure Wireshark, capture filters vs display filters, follow TCP streams, identify HTTP POSTs.

# Example capture filter to find HTTP POSTs
wireshark -f "tcp port 80 and http.request.method == POST"

11:00 – 12:00 — Home Network Hardening Lab

Activities: Configure WPA3 where possible, create guest VLANs for IoT, capture traffic and identify suspicious DNS queries.

Deep Topic — Packet-level Indicators & Forensics

Explanation: Packet forensics is about retrieving context from headers and payloads to understand attacker behaviour. This includes timestamps, sequence numbers, packet sizes, and protocol anomalies.

Example: A series of HTTP POSTs to an unusual external IP with base64-encoded payloads could indicate credential exfiltration. Correlate with DNS queries and TLS SNI to build attribution.

Tools & Commands:

  • Wireshark — deep packet inspection, protocol dissectors.
  • tshark — CLI packet parsing for automation.
  • tcpdump — capture traffic on remote hosts.
# capture HTTP POSTs to inspect with Wireshark/tshark
tcpdump -i eth0 -s 0 -w capture.pcap tcp port 80 and 'tcp[((tcp[12] & 0xf0) >> 2):4] = 0x504f5354'

"Packet by packet, we reconstruct the attacker's story." — Tshepho Nkoe

09:00 – 09:30 — Intro: Cloud Threats & Reconnaissance

Why it matters: Cloud misconfigurations (S3 exposures, IAM errors) and metadata service leaks are high-risk. Attackers enumerate metadata endpoints (169.254.169.254) to steal credentials.

# Example (lab-only) metadata check
curl http://169.254.169.254/latest/meta-data/

Understanding API discovery and fuzzing helps defenders map exposures and reduce blast radius.

09:30 – 10:30 — Cloud IDS Deployment & SIEM Platforms

Cloud IDS options: GuardDuty (AWS), Alibaba Threat Detection, Yandex Security Scanner. Each offers built-in telemetry and ML-based anomaly detection; however, exporting findings to a central SIEM (Elastic/Splunk) is essential for correlation.

Quick Suricata install (lab):

sudo apt update && sudo apt install suricata -y
echo 'HOME_NET: [10.0.0.0/16]' | sudo tee -a /etc/suricata/suricata.yaml
sudo systemctl restart suricata
tail -f /var/log/suricata/fast.log | grep "HTTP"

Design note: Consider data residency — send only alerts to centralized SIEM while keeping raw logs in-region to comply with GDPR/PIPL where required.

10:45 – 11:30 — Honeypot Engineering & Deception Tactics

What honeypots do: They attract attackers, gather IoCs, and reveal automated scripts or human-driven attempts. Effective honeypots mimic real services with convincing responses and telemetry.

Simulated T-Pot deployment (lab only):

sudo apt install docker.io -y
git clone https://github.com/telekom-security/tpotce && cd tpotce
sudo ./install.sh --type=user

# add fake banking endpoint
echo '{"service":"bank_api","port":8080}' | sudo tee /opt/tpot/etc/compose/fake_api.json
sudo docker-compose up -d
tail -f /data/tpot/log/nginx/access.log | grep "POST /login"

"A good trap teaches more than it punishes." — Tshepho Nkoe

Analysis: Search logs for repeated POSTs, suspicious user-agent strings, or credential stuffing patterns. Turn frequent probes into Suricata signatures to detect attempts in production networks.

Day 7.3 — Stealth Networking for Global Teams
"The best encryption is useless if they know you're using it. Obfuscation is the art of hiding in plain sight." — Tshepho Nkoe

Why This Session Matters

With 40%+ of countries imposing some level of internet restrictions and DPI-based blocking becoming common, remote teams need resilient, privacy-respecting ways to communicate and collaborate across borders. This module covers obfuscation techniques, legal considerations, and operational design patterns for resilient connectivity.

Learning Objectives
  • Deploy obfuscated VPNs (Shadowsocks, WireGuard + obfs4).
  • Map legal risks (GDPR, PIPL, Yarovaya) and design compliant routing choices.
  • Apply federated auth and microsegmentation for secure access.
  • Forecast 2030 trends: AI-driven obfuscation, decentralized VPNs.
09:00 – 09:30 — Obfuscation Fundamentals

Core concepts:

  • Protocol mimicry: Make VPN traffic resemble HTTPS/VoIP (V2Ray).
  • Traffic splitting: Send sensitive streams via obfuscated channel and bulk traffic via standard ISP path.
  • Federated auth: Use SSO (Keycloak, Azure AD) with device-based checks for VPN access.

Mini-case: In 2023, several fintech teams using Shadowsocks-over-TLS reported successful bypassing of DPI filters in targeted regions — the lesson is to pair obfuscation with legal review and careful operational hygiene.

09:30 – 10:30 — Hands-On Stealth VPNs

Lab 1 — Shadowsocks (HTTPS-style obfuscation)

# server (lab VM)
sudo apt update
sudo apt install shadowsocks-libev -y
ss-server -s 0.0.0.0 -p 443 -k "YourStrongPassword" -m aes-256-gcm -t 300 --fast-open

Note: Run in authorized lab VPS only. Port 443 with TLS wrappers reduces DPI signatures but must be used with legal awareness.

Lab 2 — WireGuard + obfs4 (Docker)

version: '3'
services:
  wireguard:
    image: linuxserver/wireguard
    ports:
      - "51820:51820/udp"
    volumes:
      - ./config:/config
  obfs4:
    image: dazn/obfs4proxy
    command: -enableLogging -server 0.0.0.0:12345
    ports:
      - "12345:12345/tcp"

Discussion: obfs4 reduces UDP fingerprinting; tradeoffs include MTU, latency, and maintainability for larger teams.

10:45 – 11:30 — Legal & Operational Strategies

Legal points: Map national obligations (data retention, interception orders) before deploying cross-border routing. In some countries, unauthorized VPN use is illegal; enterprise risk must be assessed.

Operational controls:

  • Federated authentication (Tailscale + SSO) to provide per-user access control.
  • No-logs policies for privacy, combined with in-region log retention when required by law.
  • "Legal Twin Zones" — route traffic via jurisdictions with favorable legal posture in emergency scenarios.

"Security is not just technical; it is legal and ethical. Know your boundaries." — Tshepho Nkoe

11:30 – 12:00 — 2030 Connectivity Forecast
  • AI Traffic Sculpting: ML models that style traffic patterns to more closely match benign flows, reducing false positives for obfuscation.
  • Decentralized VPNs: Blockchain-based routing marketplaces (e.g., Orchid) enabling multi-hop, reputation-backed routing.
  • Encrypted SNI & TLS advances: Wider adoption makes passive SNI inspection less effective; active probing may evolve.

Discussion prompt: "Will quantum or AI make obfuscation obsolete or stronger by 2030?" — students should consider cryptography, detection arms-race, and legal factors in their answers.
