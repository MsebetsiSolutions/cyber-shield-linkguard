Day 1: Kali Linux Setup & Cyber Reconnaissance

4 Hours

Learning Objectives

  • Set up Kali Linux or equivalent systems for reconnaissance
  • Perform passive OSINT using Google Dorking, Shodan, and theHarvester
  • Conduct active reconnaissance using Nmap and banner grabbing
  • Map reconnaissance phases to the MITRE ATT&CK framework and NIST CSF
  • Understand the relevance of cyber reconnaissance in global cyber operations

Introduction to Cyber Reconnaissance
Video

Cyber reconnaissance is the first phase in most cyberattacks, where adversaries gather information about their target prior to exploitation.

Real-World Case Study: SolarWinds (2020)

Attackers performed passive recon on public repositories, domains, and update mechanisms before injecting malicious code into software updates.

Hands-On: Passive Recon & OSINT Intelligence
Video

Google Dorking

inurl:/view/index.shtml → Find exposed webcams
intitle:"Admin Panel" site:.gov → Unprotected login portals
filetype:sql → Search for leaked database files

Shodan

port:3389 country:US → Open RDP servers
port:554 has_screenshot:true → Public camera feeds

theHarvester

theHarvester -d example.com -b google

Active Reconnaissance: Scanning & Enumeration
Video

Nmap Scanning Techniques

nmap -sn 192.168.1.0/24 # Discover live hosts
nmap -p 22,80,443 target.com # Specific ports
nmap -A target.com # Aggressive scan + OS fingerprinting

Banner Grabbing & Enumeration

nc -v target.com 80 # Grab HTTP banner
nmap -sV -p 21,22,80,443 target.com # Service version detection

Introduction to Exploitation
Video

Exploitation involves taking advantage of vulnerabilities in systems to gain unauthorized access or control.

Real-World Case Study: Log4Shell (2021)

RCE vulnerability in Apache Log4j library allowed attackers to execute arbitrary code, leading to lateral movement and data exfiltration.

Remote Code Execution (RCE) Lab
