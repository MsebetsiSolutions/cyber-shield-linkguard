📋 CSS Selectors Overview

CSS selectors are patterns used to select the HTML elements you want to style. This activity will help you understand different types of selectors and how to use them effectively.

🎯 Learning Objectives

  • Learn to use class and ID selectors
  • Practice writing CSS rules for specific elements
  • Understand selector specificity
  • Apply selectors to style HTML elements

🚀 CSS Selector Types

1. Class Selectors

Target elements with specific class attributes using the dot (.) notation

.box-blue { background-color: blue; }

2. ID Selectors

Target a single element with a specific ID using the hash (#) notation

#box-orange { background-color: orange; }

3. Element Selectors

Target all elements of a specific type

section { border: 1px solid black; }

4. Descendant Selectors

Target elements that are descendants of other elements

section p { color: white; }

5. Grouping Selectors

Apply the same styles to multiple selectors

.box-blue, #box-orange { padding: 20px; }

6. Specificity Rules

ID selectors > Class selectors > Element selectors

#box-orange overrides .box-blue

✅ Solved CSS Example

Reference this completed CSS file to check your work:

style.css Completed Solution 
/* Style all boxes with padding and border */
section {
  padding: 20px;
  border: 2px solid;
  border-radius: 8px;
  margin: 10px;
  width: 100px;
  height: 100px;
  display: flex;
  align-items: center;
  justify-content: center;
}

/* Style blue boxes using class selector */
.box-blue {
  background-color: #3498db;
  border-color: #2980b9;
}

/* Style orange box using ID selector */
#box-orange {
  background-color: #e67e22;
  border-color: #d35400;
}

/* Center text in all boxes */
section {
  text-align: center;
}

/* Make text white in blue boxes */
.box-blue p {
  color: white;
  font-weight: bold;
}

/* Make text white in orange box */
#box-orange p {
  color: white;
  font-weight: bold;
}

/* Add hover effect to orange box */
#box-orange:hover {
  background-color: #f39c12;
  transform: scale(1.05);
  transition: all 0.3s ease;
}
