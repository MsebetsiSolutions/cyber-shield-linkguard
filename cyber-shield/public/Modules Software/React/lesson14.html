Push to GitHub

Initialize Git repository and push to GitHub.

$ git init
$ git add .
$ git commit -m "Initial commit"
$ git branch -M main
$ git remote add origin [repo-url]
$ git push -u origin main
3

Deploy to Vercel

Deploy your application to Vercel with GitHub integration.

1. Go to vercel.com
2. Click "Import Project"
3. Select GitHub repository
4. Click "Deploy"
5. Wait 1-2 minutes
6. 🎉 Your site is live!
4

Deploy to Netlify

Alternative deployment option with Netlify.

1. Go to netlify.com
2. Drag & drop build folder
3. Or connect GitHub repo
4. Add build settings if needed
5. Deploy!

Troubleshooting Common Issues

White Screen on Deployment

Common issue caused by wrong paths in index.html

<!-- Change this -->
<link rel="stylesheet" href="/static/css/main.css">
<!-- To this -->
<link rel="stylesheet" href="./static/css/main.css">
API Calls Fail After Deployment

Environment variables not configured properly

// .env.local (development)
REACT_APP_API_KEY=your_key_here
REACT_APP_API_URL=http://localhost:3000

// In Vercel/Netlify dashboard, add:
REACT_APP_API_KEY=production_key_here
REACT_APP_API_URL=https://api.msebetsisolutions.com
Routing Issues (404 on Refresh)

Single Page Application routing needs configuration

// Create src/_redirects (Netlify)
/* /index.html 200

// Or configure in vercel.json
{
  "rewrites": [{ "source": "/(.*)", "destination": "/index.html" }]
}
Build Fails

Clear cache and rebuild to fix dependency issues

# Clear cache and rebuild
rm -rf node_modules
rm -rf build
npm cache clean --force
npm install
npm run build
