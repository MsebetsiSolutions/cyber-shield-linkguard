Netflix's Styling Approach

We use different methods for different components:

CSS Modules (Recommended)

// NetflixVideoPlayer.module.css
.videoPlayer {
  background: var(--netflix-black);
  border-radius: var(--radius-lg);
  color: var(--netflix-white);
}

.playButton {
  background: var(--gradient-red);
  transition: var(--transition-normal);
}

.playButton:hover {
  transform: scale(1.1);
  box-shadow: var(--shadow-red);
}

Styled Components

import styled from 'styled-components';

const NetflixButton = styled.button`
  background: \${props => props.primary ? '#E50914' : 'transparent'};
  color: \${props => props.primary ? 'white' : '#E50914'};
  border: 2px solid #E50914;
  padding: 12px 24px;
  border-radius: 4px;
  font-weight: 700;
  cursor: pointer;
  transition: all 0.3s ease;
  
  &:hover {
    transform: translateY(-2px);
    box-shadow: 0 6px 20px rgba(229, 9, 20, 0.25);
  }
`;

Netflix Testing Standards

All Netflix components must pass these tests:

Jest Test Suite

// NetflixVideoPlayer.test.js
import { render, screen } from '@testing-library/react';
import NetflixVideoPlayer from './NetflixVideoPlayer';

describe('NetflixVideoPlayer', () => {
  test('renders with Netflix styling', () => {
    render(<NetflixVideoPlayer />);
    expect(screen.getByText(/LIVE/i)).toBeInTheDocument();
  });

  test('play/pause functionality works', () => {
    render(<NetflixVideoPlayer />);
    const playButton = screen.getByRole('button', { name: /play/i });
    fireEvent.click(playButton);
    expect(screen.getByText(/NOW PLAYING/i)).toBeInTheDocument();
  });
});
