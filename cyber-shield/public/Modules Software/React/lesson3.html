What is JSX?

JSX (JavaScript XML) is a syntax extension that allows you to write HTML-like code in JavaScript. Msebetsi Solutions uses JSX extensively because:

Readable & Familiar

Looks like HTML, works like JavaScript - easy for teams to understand.

Component-Based

Break UI into reusable pieces (VideoPlayer, Controls, ProgressBar).

Type-Safe

Catches errors during compilation, not at runtime.

JSX vs HTML: Key Differences

Msebetsi Solutions engineers must understand these critical differences:

Important JSX Rules 
// 1. className instead of class
<div className="video-player">
  <button className="play-btn">▶</button>
</div>

// 2. camelCase for event handlers
<button onClick={handlePlay}>
  Play
</button>

// 3. Self-closing tags
<img src="thumbnail.jpg" alt="Preview" />

// 4. JavaScript expressions in {}
<h3>{movieTitle} ({currentTime}/{duration})</h3>

JSX Mastery Quiz

1. Which JSX syntax correctly renders a dynamic title and progress?
<h3>{movieTitle} ({currentTime}/{duration})</h3>
<h3>"movieTitle" (currentTime/duration)</h3>
<h3>${movieTitle} (${currentTime}/${duration})</h3>
<h3>movieTitle + " (" + currentTime + "/" + duration + ")"</h3>
2. How do you conditionally render the "Now Playing" indicator?
{isPlaying && <div className="playing">NOW PLAYING</div>}
<div className="playing" show={isPlaying}>NOW PLAYING</div>
<div className={isPlaying ? "playing" : ""}>NOW PLAYING</div>
<div className="playing">{isPlaying ? "NOW PLAYING" : ""}</div>
