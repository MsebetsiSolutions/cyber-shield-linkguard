useEffect Lifecycle Flow

Visualize the complete lifecycle of useEffect hooks in React. See how Netflix manages side effects across component mounts, updates, and unmounts.

Component Mount

When the component first renders to the screen. useEffect runs once to fetch initial data, set up subscriptions, or initialize state.

Runs: Once on mount

Dependency Updates

When dependencies in the array change. useEffect re-runs to synchronize with new data, update UI, or fetch fresh content.

Runs: On dependency change

Cleanup Phase

Before the component unmounts or before the next effect runs. Clean up subscriptions, timers, or abort ongoing requests.

Runs: Before unmount/next effect

Continue Watching Simulation

Netflix's useEffect Implementation

import React, { useEffect, useState } from 'react';
const ContinueWatching = () => {
  const [watchHistory, setWatchHistory] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);
// useEffect with cleanup and dependency array
useEffect(() => {
let isMounted = true;
const abortController = new AbortController();
const fetchWatchHistory = async () => {
try {
setLoading(true);
const response = await fetch(
'/api/watch-history',
{ signal: abortController.signal }
);
if (!response.ok) {
throw new Error('Failed to fetch watch history');
}
const data = await response.json();
if (isMounted) {
setWatchHistory(data);
setError(null);
}
} catch (err) {
if (isMounted && err.name !== 'AbortError') {
setError(err.message);
}
} finally {
if (isMounted) {
setLoading(false);
}
}
};
fetchWatchHistory();
// Cleanup function
return () => {
isMounted = false;
abortController.abort();
};
}, []); // Empty dependency array = runs once on mount
return (
<div className="continue-watching">
{loading && <LoadingSkeleton />}
{error && <ErrorMessage message={error} />}
{!loading && !error && watchHistory.map((item) => (
<ContinueCard key={item.id} item={item} />
))}
</div>
);
};
