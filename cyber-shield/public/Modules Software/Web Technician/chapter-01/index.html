Command Line Navigation & File Management

Why the Command Line Matters

Modern developers rely heavily on the terminal to move through folders, automate tasks, and run developer tools. The command line lets you navigate faster than with a mouse, create and manage files quickly, automate repetitive tasks, and run tools like git, Node.js, Docker, and Python. Every serious software engineer should be comfortable with the CLI.

Quick start — Open your terminal and follow along

Below are the essential commands you should practice. Each block shows the command for macOS/Linux (Bash/Zsh) and Windows PowerShell.

1. List the contents of your current directory

macOS / Linux
ls
Windows PowerShell
Get-ChildItem

You should see folders such as Desktop, Documents, and Downloads.

2. Change to another directory

macOS / Linux
cd Desktop
Windows PowerShell
Set-Location Desktop

3. Move back to the previous directory

macOS / Linux
cd ..
Windows PowerShell
Set-Location ..

4. Check your current working directory

macOS / Linux
pwd
Windows PowerShell
Get-Location

5. Create a new folder inside Desktop

Navigate back into Desktop if needed: cd Desktop

macOS / Linux
mkdir demo-folder
Windows PowerShell
New-Item -Name "demo-folder" -ItemType "directory"

6. Enter the new folder

cd demo-folder

Windows PowerShell uses the same cd command.

7. Create a new file

macOS / Linux
touch index.html
Windows PowerShell
New-Item -Name "index.html" -ItemType "file"

8. Confirm your file exists

ls
Get-ChildItem

You should now see index.html in the folder.

Bonus Challenge — Level up your terminal skills

Research and practice the following commands and concepts:

  • rm / Remove-Item — delete files
  • cp / Copy-Item — copy files
  • mv / Move-Item — rename or move files
  • tree — visual directory structure (installable on most OS)
  • code . — open folder in VS Code directly from terminal
