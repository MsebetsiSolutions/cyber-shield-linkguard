🏗️ Task Context: Employee Professional Identity

Create a professional digital identity page for Msebetsi Solutions employees that presents role, photo, bio, and contact links for verification by colleagues, partners, and potential clients.

🎯 User Story

As an employee of Msebetsi Solutions, I want a professional digital identity page that presents my role, photo, bio, and contact links so that colleagues, partners, and potential clients can quickly verify my credentials and contact me.

✅ Key Features

  • Professional employee profile with photo
  • Role and bio information
  • Contact links (email, LinkedIn, directory)
  • Accessible markup and responsive design
  • JSON-LD structured data
  • Mobile-responsive layout

🚀 Implementation Goals

1. Professional Identity Presentation

Create a clean, professional layout that presents employee information clearly and attractively. The design should reflect Msebetsi Solutions' brand identity while maintaining individual professional presence.

2. Responsive & Accessible Design

Implement a mobile-first responsive design that works across all devices. Ensure the page meets WCAG accessibility standards with proper ARIA labels, semantic HTML, and keyboard navigation support.

3. SEO & Structured Data

Add JSON-LD structured data using Schema.org vocabulary for Person and Organization. This helps search engines understand and display employee information in search results.

4. Contact Integration

Implement proper contact mechanisms including mailto links, LinkedIn profile integration, and internal directory links that open in new tabs for security.
