🔧 Project Scenario

Company: Msebetsi Solutions

Task: Refactor the company's employee profile page to use proper HTML5 semantic elements and improve the layout structure.

Current Issues:

  • Excessive use of <div> elements
  • Poor semantic structure

Expected Outcomes:

  • Proper use of semantic HTML5 elements
  • Enhanced accessibility (WCAG compliance)
  • Responsive layout using CSS Grid/Flexbox
  • Improved SEO through structured data
  • Better performance and maintainability

✅ Activity Tasks

Complete the following tasks to transform the non-semantic profile page into a modern, accessible component:

  1. Task 1: Replace Generic Divs

    Replace at least 5 generic <div> elements with appropriate semantic HTML5 elements.

    • Use <header>, <main>, <section>, <article>, <aside>
    • Add proper ARIA landmarks where needed
    • Ensure proper heading hierarchy (h1-h6)

  2. Task 2: Add Semantic Text Elements

    Enhance text content with semantic elements:

    • Use <time> for dates
    • Add <address> for contact information
    • Include <figure> and <figcaption> for images
    • Use <mark> for highlighted text

  3. Task 3: Implement Accessibility Features

    Add accessibility attributes and features:

    • Add alt text to all images
    • Include ARIA labels and roles
    • Ensure keyboard navigation support
    • Add skip navigation links

  4. Task 4: Create Responsive Layout

    Build a responsive layout using modern CSS:

    • Implement CSS Grid for main layout
    • Use Flexbox for component layouts
    • Add responsive typography
    • Ensure mobile-first design

  5. Task 5: Add Structured Data

    Include structured data for SEO:

    • Add JSON-LD structured data
    • Implement microdata attributes
    • Include Open Graph meta tags
    • Add Twitter Card meta tags

✅ Expected Solution Preview

Here's what your enhanced semantic HTML should look like:

Enhanced Semantic Structure 
<!-- Semantic HTML5 Structure -->
<main class="profile" role="main" aria-label="Employee Profile">
    
    <header class="profile-header">
        <h1>John Doe</h1>
        <p class="title">Senior Developer</p>
        <time datetime="2023-01-15">Joined: January 15, 2023</time>
    </header>
    
    <article class="profile-content">
        <figure class="profile-image">
            <img src="profile.jpg" alt="Professional headshot of John Doe">
            <figcaption>John Doe, Senior Developer</figcaption>
        </figure>
        
        <section class="profile-info" aria-labelledby="bio-heading">
            <h2 id="bio-heading">Professional Bio</h2>
            <p>Experienced developer specializing in web technologies...</p>
        </section>
        
        <aside class="contact-info" role="complementary">
            <h2>Contact Information</h2>
            <address>
                Email: <a href="mailto:john@example.com">john@example.com</a><br>
                Phone: <a href="tel:+27123456789">+27 123 456 789</a>
            </address>
        </aside>
    </article>
    
</main>
