JavaScript Concepts

Understanding functions, hoisting, and equality operators

Function Declarations

Declared using the function keyword. They are hoisted - can be called before declaration.

function validateData(a, b) {
    return a === b;
}

Function Expressions

Assigned to variables. They are NOT hoisted - must be defined before calling.

const validateData = function(a, b) {
    return a === b;
};

Equality Operators

=== Strict Equality

Same type AND same value

  • 5 === 5 ✅ true
  • 5 === "5" ❌ false

== Loose Equality

Same value after type conversion

  • 5 == 5 ✅ true
  • 5 == "5" ✅ true

Production Incident: The R15,000 Bug

❌ The Bug That Failed:

// Function called BEFORE declaration
console.log("Validating...");
validateTransaction(5000, "5000"); // ERROR!

// ... Later in the file ...
const validateTransaction = function(a, b) {
    return a === b;
};

✅ The Fix That Worked:

// Option 1: Use function declaration
function validateTransaction(a, b) {
    return a === b;
}
console.log("Validating...");
validateTransaction(5000, "5000"); // WORKS!

// Option 2: Define expression first
const validateTransaction = function(a, b) {
    return a === b;
};
console.log("Validating...");
validateTransaction(5000, "5000"); // WORKS!

Lesson Learned: Always understand hoisting behavior. Function declarations are hoisted, expressions are not.
