UEBA Deep Dive Core Concept
Video

User and Entity Behavior Analytics (UEBA) applies machine learning to detect suspicious or abnormal user/device behavior by establishing baselines and flagging deviations.

Traditional SIEM vs. UEBA

SIEM: Rule-Based (Alert: 5 failed logins) → UEBA: Behavior-Based (Alert: user downloads HR files at 3 AM)

APT Hunting with Sigma & MITRE ATT&CK Advanced
Video

Advanced Persistent Threats (APTs) use custom malware, remote access tools (RATs), and stealthy persistence techniques to target governments, critical infrastructure, and supply chains.

Sigma Rules

Sigma is a vendor-neutral detection format (YAML) that can be converted into queries for Elastic, Splunk, ArcSight, etc.

# Sigma Rule to Detect Process Creation (APT Example)
detection:
selection:
EventID: 4688
CommandLine|contains:
- "rundll32.exe"
- "http://"
condition: selection
# Convert to Elastic query
sigmac -t elastalert rules/windows/apt_cozybear.yml
