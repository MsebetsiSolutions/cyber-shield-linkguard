Set Up a Local Repository with Git

Master Git from Scratch • Initialize, Commit & Pull Like a Pro!

In this activity, we will explore configuring the local Git default branch to main. We will also review another way to create a repository using the git init command. Lastly, we will review the git pull command.

Git is an essential tool that allows developers to track and store versions of content. It enables collaboration and sharing code with others. During this bootcamp, you'll use Git to pull class materials and submit Challenges via GitHub.

For more information, review the Full-Stack Blog guide on getting started with Git.

Configure Local Git Default Branch to main

Historically, the default branch was called master, but now main is the modern standard — used by GitHub and all projects in this course.

Important: If you've already configured your local default branch to main, skip this step.

First, check your Git version:

git --version

If your version is 2.28 or older, update Git:

  • Windows: Download from git-scm.com
  • Mac (with Homebrew):
brew upgrade git

Set the global default branch to main:

git config --global init.defaultBranch main

Initialize a Local Repository

Let’s create a repository locally using git init — perfect for turning any project into a Git repo.

mkdir git-init-sample
cd git-init-sample
touch index.html

Initialize the Git repository:

git init

Check status and stage all files:

git status
git add -A

Make your first commit:

git commit -m "initial commit"

Connect to GitHub (Remote Repository)

Create a new repository on GitHub called git-init-sample without initializing README, .gitignore, or license.

Then run these commands (copy from GitHub):

git remote add origin https://github.com/your-username/git-init-sample.git
git branch -M main
git push -u origin main
Note: If you already set init.defaultBranch to main, you can skip git branch -M main.
[Success message: Project successfully pushed to GitHub]

Pull Changes from the Remote Repository

Always pull the latest class materials before starting:

cd git-init-sample
git pull origin main

You’ll see either:

  • "Already up to date" → You're good!
  • New files downloaded → Open in VS Code!
