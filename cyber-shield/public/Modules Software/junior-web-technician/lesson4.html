📋 Activity Overview

This activity guides you through the complete professional workflow for creating and managing a GitHub repository. Follow the steps below to complete the task.

🎯 Learning Objectives

  • Create a GitHub repository via web interface
  • Clone repository using SSH authentication
  • Use Git commands for version control
  • Implement proper commit messages
  • Push changes to remote repository

✅ Acceptance Criteria

  • Repository named "first-day-repo" created
  • Repository cloned to local machine
  • index.html file created via terminal
  • Changes committed with descriptive message
  • Changes pushed to GitHub successfully

🚀 Professional Workflow Steps

1. Create GitHub Repository

Navigate to GitHub.com and create a new repository named "first-day-repo"

Repository URL: https://github.com/your-username/first-day-repo

2. Clone Repository (SSH)

Clone the repository to your local machine using SSH

git clone git@github.com:your-username/first-day-repo.git

3. Navigate to Repository

Change directory to the cloned repository

cd first-day-repo

4. Create HTML File

Create an index.html file from terminal

touch index.html

5. Stage and Commit

Add file to staging and commit with message

git add index.html
git commit -m "Added index.html file"

6. Push to GitHub

Push your changes to the remote repository

git push origin main
