PART 1: INSTALLING POSTGRESQL

PREREQUISITES: Basic computer literacy, Terminal/Command Prompt access, Administrative rights
1

For Windows Users

1. Download installer from postgresql.org/download/windows/

2. Run the installer and follow the setup wizard

3. Remember your password - you'll need it later!

4. Use default port: 5432

5. Complete installation

2

For Mac Users

# Option 1: Using Homebrew
brew install postgresql@14
brew services start postgresql@14

# Option 2: Download from postgresql.org/download/macosx/
3

For Linux (Ubuntu/Debian)

sudo apt update
sudo apt install postgresql postgresql-contrib
sudo systemctl start postgresql
4

Verification Check

psql --version

Expected output: psql (PostgreSQL) 14.x

PART 2: POSTGRESQL SHELL BASICS

Connecting to PostgreSQL

# Connect as default superuser
psql -U postgres

# Connect to specific database
psql -U postgres -d database_name

# Connect with host and port
psql -h localhost -p 5432 -U postgres

Common psql Commands

Command What it does Example
\l List all databases \l
\c Connect to database \c mydatabase
\dt List tables \dt
\d table_name Describe table \d users
\q Quit psql \q
\i Execute SQL file \i setup.sql

PART 3: CREATING YOUR FIRST DATABASE & TABLE

1

Create a Database

-- First, connect to PostgreSQL
psql -U postgres

-- Create your first database
CREATE DATABASE school_db;

-- Verify it was created
\l

-- Connect to your new database
\c school_db
2

Create Your First Table

-- Create a simple students table
CREATE TABLE students (
    student_id SERIAL PRIMARY KEY,
    first_name VARCHAR(50) NOT NULL,
    last_name VARCHAR(50) NOT NULL,
    email VARCHAR(100) UNIQUE,
    enrollment_date DATE DEFAULT CURRENT_DATE,
    gpa DECIMAL(3,2) CHECK (gpa >= 0.0 AND gpa <= 4.0)
);

-- Verify table creation
\dt
\d students
UNDERSTANDING TABLE STRUCTURE: 
students
├── student_id (SERIAL, PRIMARY KEY) → Auto-incrementing unique ID
├── first_name (VARCHAR(50), NOT NULL) → Required text field
├── last_name (VARCHAR(50), NOT NULL) → Required text field
├── email (VARCHAR(100), UNIQUE) → Unique email address
├── enrollment_date (DATE, DEFAULT) → Auto-fills with today's date
└── gpa (DECIMAL(3,2), CHECK) → Number with constraint (0.0-4.0)

PART 4: CORE SQL COMMANDS INTRODUCTION

SQL Command Categories

DDL (Data Definition Language)

-- CREATE - Make new database objects
CREATE DATABASE company_db;
CREATE TABLE employees (...);

-- ALTER - Modify existing objects
ALTER TABLE students ADD COLUMN phone VARCHAR(15);

-- DROP - Remove objects
DROP TABLE IF EXISTS temp_data;

DML (Data Manipulation Language)

-- INSERT - Add new records
INSERT INTO students (first_name, last_name, email)
VALUES ('John', 'Doe', 'john@email.com');

-- SELECT - Retrieve data
SELECT * FROM students;

-- UPDATE - Modify existing data
UPDATE students SET gpa = 3.8
WHERE student_id = 1;

DCL (Data Control Language)

-- GRANT - Give permissions
GRANT SELECT ON students TO analyst_role;

-- REVOKE - Remove permissions
REVOKE DELETE ON students FROM intern_role;

TCL (Transaction Control Language)

-- BEGIN - Start transaction
BEGIN;
INSERT INTO students ...;
UPDATE grades ...;
COMMIT; -- Save changes

-- ROLLBACK - Undo changes
BEGIN;
DELETE FROM test_data;
ROLLBACK;

PART 5: PRACTICE EXERCISE

Hands-On Activity

Create a file called school_setup.sql with the following content:

-- school_setup.sql
DROP DATABASE IF EXISTS practice_db;
CREATE DATABASE practice_db;

\c practice_db;

-- Create teachers table
CREATE TABLE teachers (
    teacher_id SERIAL PRIMARY KEY,
    full_name VARCHAR(100) NOT NULL,
    subject VARCHAR(50),
    hire_date DATE DEFAULT CURRENT_DATE
);

-- Create courses table
CREATE TABLE courses (
    course_id SERIAL PRIMARY KEY,
    course_name VARCHAR(100) NOT NULL,
    teacher_id INT REFERENCES teachers(teacher_id),
    credits INT DEFAULT 3
);

-- Insert sample data
INSERT INTO teachers (full_name, subject) VALUES
('Dr. Smith', 'Mathematics'),
('Prof. Johnson', 'Computer Science');

INSERT INTO courses (course_name, teacher_id, credits) VALUES
('Calculus I', 1, 4),
('Database Design', 2, 3);

-- View results
SELECT * FROM teachers;
SELECT * FROM courses;

Execute Your File

# From terminal
psql -U postgres -f school_setup.sql

# OR from within psql
\i school_setup.sql

SQL Syntax Rules:
  1. End with semicolon: Every SQL statement must end with ;
  2. Case insensitive: SELECT = select = Select
  3. Single quotes for text: 'John' not "John"
  4. Comments: Use -- for single line, /* */ for multi-line
