📚 Lesson 15: CSS Display Property

Msebetsi Solutions Software Development Course

Learn how to control element layout with CSS display property

👨‍🏫 Instructor Note: In this lesson, we'll explore how HTML elements naturally behave (inline vs block) and how we can override this behavior using CSS display property. This is crucial for building responsive layouts!

📝 Understanding Default Display Values

/* Every HTML element has a default display value */

1. Inline Elements

Characteristics: Sit side-by-side, width determined by content, cannot set width/height

Common examples: <span>, <a>, <img>, <strong>, <em>

<!-- Anchor elements are inline by default -->

💡 Real-world Example: Navigation menus use inline display for horizontal links. Try resizing your browser to see how inline elements wrap naturally.

2. Block Elements

Characteristics: Start on new line, take full available width, can set width/height

Common examples: <div>, <p>, <h1>-<h6>, <ul>, <li>, <section>

🎨 CSS Display Property Overrides

/* We can change default display behavior with CSS */

3. display: inline

Changes block elements to behave like inline elements

<!-- These paragraphs would normally stack -->

📝 Paragraphs with display: inline

Paragraph 1 (now inline)

Paragraph 2 (now inline)

Notice they sit side-by-side

⚠️ Warning: When you make block elements inline, you lose the ability to set width, height, and vertical margins properly.

4. display: block

Changes inline elements to behave like block elements

<!-- These images would normally sit side-by-side -->

🖼️ Images with display: block

Image 1 (now block)
Image 2 (now block)

Images now stack vertically instead of sitting side-by-side

5. display: none

Completely removes element from document flow

🎭 Hidden List Demo:

The list below has display: none applied:

  • This list item is hidden
  • This list item is also hidden

↑ The list above exists in HTML but is not visible on the page.

🔍 Important Distinction: display: none removes the element entirely, while visibility: hidden just makes it invisible but it still takes up space.

6. display: inline-block

Best of both worlds: sits side-by-side but accepts width/height

🏋️‍♂️ Msebetsi Solutions Practice Exercise

Task: Create a simple navigation menu

  1. Create 5 anchor tags (<a>) for Home, About, Services, Portfolio, Contact
  2. By default, they'll appear inline (side-by-side)
  3. Add a class and use CSS to make them display as block elements
  4. Observe how they stack vertically
  5. Now change them to display: inline-block and add padding, background colors

Challenge: Create a button that toggles between displaying a sidebar with display: block and hiding it with display: none.

🎯 Lesson Summary

Key Takeaways:

  • ✅ Inline: Side-by-side, content-based width
  • ✅ Block: Full width, starts new line
  • ✅ Inline-block: Hybrid approach
  • ✅ None: Completely hidden

Here's the complete solution for the navigation menu exercise:

HTML & CSS Solution 
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Navigation Menu Exercise</title>
  <style>
    * {
      margin: 0;
      padding: 0;
      box-sizing: border-box;
      font-family: Arial, sans-serif;
    }
    
    body {
      padding: 20px;
      background-color: #f8f9fa;
    }
    
    h1 {
      color: #2c3e50;
      margin-bottom: 30px;
      text-align: center;
    }
    
    h2 {
      color: #34495e;
      margin: 30px 0 15px 0;
      border-bottom: 2px solid #3498db;
      padding-bottom: 5px;
    }
    
    /* Navigation styling */
    .navbar {
      background-color: #2c3e50;
      padding: 15px;
      margin-bottom: 30px;
      border-radius: 5px;
    }
    
    /* Default inline behavior */
    .nav-link {
      color: white;
      text-decoration: none;
      margin: 0 10px;
    }
    
    /* Block behavior */
    .nav-link.block {
      display: block;
      margin: 10px 0;
      padding: 10px;
      background-color: #34495e;
      border-radius: 3px;
    }
    
    /* Inline-block behavior */
    .nav-link.inline-block {
      display: inline-block;
      padding: 10px 20px;
      margin: 0 5px;
      background-color: #3498db;
      border-radius: 4px;
      transition: all 0.3s ease;
    }
    
    .nav-link.inline-block:hover {
      background-color: #2980b9;
      transform: translateY(-2px);
      box-shadow: 0 4px 8px rgba(0,0,0,0.2);
    }
    
    /* Toggle sidebar example */
    .sidebar {
      background-color: #ecf0f1;
      padding: 20px;
      width: 250px;
      border-radius: 5px;
      margin-top: 20px;
      border-left: 4px solid #3498db;
    }
    
    .toggle-btn {
      background-color: #e74c3c;
      color: white;
      border: none;
      padding: 10px 20px;
      border-radius: 4px;
      cursor: pointer;
      margin-top: 20px;
      font-weight: bold;
      transition: background-color 0.3s ease;
    }
    
    .toggle-btn:hover {
      background-color: #c0392b;
    }
    
    .sidebar h3 {
      color: #2c3e50;
      margin-top: 0;
    }
    
    .sidebar ul {
      padding-left: 20px;
      margin: 15px 0;
    }
    
    .sidebar li {
      margin: 8px 0;
      color: #34495e;
    }
  </style>
</head>
<body>
  <h1>CSS Display Property - Navigation Menu Exercise</h1>
  
  <h2>1. Default Inline Navigation</h2>
  <p>Anchor tags are inline by default:</p>
  <nav class="navbar">
    <a href="#" class="nav-link">Home</a>
    <a href="#" class="nav-link">About</a>
    <a href="#" class="nav-link">Services</a>
    <a href="#" class="nav-link">Portfolio</a>
    <a href="#" class="nav-link">Contact</a>
  </nav>
  
  <h2>2. Block Navigation</h2>
  <p>With display: block, links stack vertically:</p>
  <nav class="navbar">
    <a href="#" class="nav-link block">Home</a>
    <a href="#" class="nav-link block">About</a>
    <a href="#" class="nav-link block">Services</a>
    <a href="#" class="nav-link block">Portfolio</a>
    <a href="#" class="nav-link block">Contact</a>
  </nav>
  
  <h2>3. Inline-Block Navigation (Recommended)</h2>
  <p>With display: inline-block, links are horizontal but accept padding/margin:</p>
  <nav class="navbar" style="text-align: center;">
    <a href="#" class="nav-link inline-block">Home</a>
    <a href="#" class="nav-link inline-block">About</a>
    <a href="#" class="nav-link inline-block">Services</a>
    <a href="#" class="nav-link inline-block">Portfolio</a>
    <a href="#" class="nav-link inline-block">Contact</a>
  </nav>
  
  <h2>4. Toggle Sidebar Challenge</h2>
  <p>Toggle the sidebar using display property:</p>
  <button class="toggle-btn" id="toggleBtn">Hide Sidebar</button>
  <div class="sidebar" id="sidebar">
    <h3>Sidebar Content</h3>
    <p>This sidebar demonstrates display: none/block toggling.</p>
    <ul>
      <li>Dashboard</li>
      <li>Profile</li>
      <li>Settings</li>
      <li>Messages</li>
    </ul>
  </div>
  
  <script>
    const toggleBtn = document.getElementById('toggleBtn');
    const sidebar = document.getElementById('sidebar');
    
    toggleBtn.addEventListener('click', () => {
      if (sidebar.style.display === 'none') {
        sidebar.style.display = 'block';
        toggleBtn.textContent = 'Hide Sidebar';
      } else {
        sidebar.style.display = 'none';
        toggleBtn.textContent = 'Show Sidebar';
      }
    });
  </script>
</body>
