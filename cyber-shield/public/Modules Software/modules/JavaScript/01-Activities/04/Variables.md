Common Student Questions:
Q: Why can't I reassign a const variable?
A: const is for values that shouldn't change (like your name). Use let for values that will change.

**Q: What's the difference between and ' ?** **A:** Backticks () allow template literals with ${variables}. Quotes don't.

Q: How do I know whether to use const or let?
A: Ask: "Will this value change during the program?" If yes → let, if no → const.
