🏆 Advanced Investigation: BigInt & Symbol

Research Challenge: Investigate these two specialized primitive types.

🔢 BigInt

Purpose: Store integers larger than 2⁵³ - 1

Syntax: Append 'n' to a number: 12345678901234567890n

Msebetsi Use Case: National budget calculations, large-scale financial systems

// Regular number limit (~9 quadrillion)
const maxSafe = 9007199254740991;

// BigInt for larger numbers
const largeBudget = 9007199254740991n * 1000n;
console.log(`National Project: R${largeBudget}`);

⚡ Symbol

Purpose: Create unique, immutable identifiers

Syntax: Symbol("description")

Msebetsi Use Case: Secure API keys, unique transaction IDs

// Creating unique identifiers
const transactionID = Symbol("txn_" + Date.now());
const apiKey = Symbol("msebetsi_api_key");

// Every Symbol is unique
Symbol("id") === Symbol("id"); // false!

🎯 Key Takeaways

✅ Primitive vs Reference

Primitives: Stored by value (7 types)

Reference: Objects, arrays, functions

typeof [] → "object" (not "array")

✅ typeof Truths

  • typeof "text" → "string"
  • typeof 42 → "number"
  • typeof true → "boolean"
  • typeof undefined → "undefined"
  • typeof null → "object" (historical bug)

✅ Msebetsi Best Practices

  • Always validate data types from APIs
  • Use const for values that won't change
  • Initialize variables to avoid undefined
  • Use typeof for type checking in functions
