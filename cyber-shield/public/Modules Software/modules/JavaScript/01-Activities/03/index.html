Activity 2: Variables - Storing Business Information

Learn how to store and manage data in JavaScript

📦 What are Variables?

Variables are containers that store data in your program. Think of them as labeled boxes where you can put information to use later.

Real-world Example: At Msebetsi Solutions, we store:
• Client names • Project budgets • Employee details • Service costs

🎯 Creating Variables (3 Ways)

1. let - For values that might change

// Declare a project variable - value might change
let projectBudget;

// Assign a value (using = assignment operator)
projectBudget = 500000;

// Or declare and assign in one line
let clientName = "ABSA Bank";

2. const - For values that won't change

// Company details that stay the same (constant)
const companyName = "Msebetsi Solutions";
const companyLocation = "Johannesburg";

// Try to change a const variable → ERROR!
// companyName = "New Name"; // Uncomment to see error

3. var - Old way (avoid in modern code)

// Old JavaScript - not recommended anymore
var oldVariable = "Avoid using var";

💼 Using Variables in Business Context

Accessing Variable Values

// To use a variable's value, just use its name
console.log(clientName);
// Output: ABSA Bank

Template Literals - Combining Text with Variables

let projectName = "E-commerce Platform";
const company = "Msebetsi Solutions";

// Old way (concatenation)
console.log('Working on: ' + projectName);

// Modern way (template literal - use backticks `)
console.log(`${company} is developing: ${projectName}`);
// Output: Msebetsi Solutions is developing: E-commerce Platform

📚 Key Takeaways

  • let = For values that might change (project budget, client requirements)
  • const = For values that won't change (company name, VAT rate, fixed costs)
  • var = Old way - don't use in new code
  • = is the assignment operator (puts value into variable)
  • Use backticks ` and ${variable} for template literals
