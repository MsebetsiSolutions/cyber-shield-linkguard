🎯 Learning Objectives

  • Implement methods that manipulate object properties
  • Use the 'this' keyword correctly in method contexts
  • Create methods that return calculated values

📋 Lab Requirements

Create a JavaScript file that implements an e-commerce system with the following objects and methods:

Product Object

Should have methods: applyDiscount(), updateStock(), getPrice()

Cart Object

Should have methods: addItem(), removeItem(), calculateTotal(), checkout()

Customer Object

Should have methods: placeOrder(), viewOrderHistory(), updateProfile()
