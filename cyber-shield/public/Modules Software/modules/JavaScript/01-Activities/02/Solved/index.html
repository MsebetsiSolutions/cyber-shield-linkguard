JavaScript Fundamentals: Console Logging

📚 What You'll Learn Today:

  • How to add JavaScript to HTML pages
  • Two methods: Inline vs External scripts
  • Using console.log() to display messages
  • Opening and reading the browser console

🔧 Method 1: Inline JavaScript

JavaScript code written directly inside HTML file:

<script> // This is inline JavaScript console.log("Hello from inline script!"); </script>
Try it: Press F12 (or right-click → Inspect) then click the Console tab

🔧 Method 2: External JavaScript

JavaScript code in separate file, linked to HTML:

<script src="script.js"></script>

Create a file named script.js with your JavaScript code.
