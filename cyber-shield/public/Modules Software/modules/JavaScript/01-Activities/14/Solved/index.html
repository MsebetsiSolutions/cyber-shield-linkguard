Understanding JavaScript Scope

Master global, local, and lexical scope concepts

Global Scope

Variables declared outside any function. Accessible everywhere.

const COMPANY = "MSEBETSI"; // Global
let department = "Support";   // Global

function sendAlert() {
    console.log(COMPANY); // ✅ Accessible
}

Local Scope

Variables declared inside a function. Only accessible within that function.

function processClient() {
    const clientId = "VIP001"; // Local
    console.log(clientId); // ✅ Works
}

console.log(clientId); // ❌ Error: Not defined

Lexical Scope

Inner functions can access variables from outer functions.

function outer() {
    const outerVar = "data";
    
    function inner() {
        console.log(outerVar); // ✅ Accessible
    }
    
    inner();
}

Scope Rules
  • ✅ Inner scopes can access outer scope variables
  • ❌ Outer scopes cannot access inner scope variables
  • ✅ Same-level scopes cannot access each other's variables
  • ✅ Variables are searched from inner to outer (scope chain)
