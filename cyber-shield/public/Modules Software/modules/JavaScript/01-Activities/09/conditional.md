Msebetsi Traffic Control: Conditional Statements Lab
Activity: Smart Business Decisions with Conditionals
Duration: 40-50 minutes
Format: Interactive Traffic Control Simulation
Learning Objectives:

Master if, else if, else statements

Understand logical operators (&&, ||, !)

Apply conditionals to business decision making

Build interactive decision systems

Activity Flow:
Part 1: Traffic Control Introduction (10 minutes)
Students explore the interactive interface:

Traffic Lights: Visual feedback for decision outcomes

Variable Display: See current project parameters

Flow Chart: Understand the decision-making process

Part 2: Interactive Decision Making (15 minutes)
Students manipulate variables and see real-time effects:

Adjust Budget: Click buttons to change project budget

Modify Deadline: See how timeline affects decisions

Change Team Size: Observe team capacity checks

Run Simulations: Test pre-configured scenarios

Part 3: Code Learning (10 minutes)
Students study the live code display:

Syntax Highlighting: Color-coded conditional statements

Live Updates: Code changes as variables update

Console Output: See decision logic in action

Part 4: Challenge & Creation (15 minutes)
Students apply their learning:

Write Conditions: Create their own priority logic

Test Logic: See if their conditions work

Compare Solutions: Review example implementations

Learning Outcomes:
Conditional Mastery: Understand if, else if, else statements

Logical Operators: Apply &&, ||, ! effectively

Decision Making: Build complex business logic

Debugging Skills: Identify and fix conditional errors

Real Application: Apply conditionals to Msebetsi scenarios

Key Features:
Visual Learning:
Traffic Light System: Red/Yellow/Green for decision outcomes

Flow Animation: Step-by-step decision process visualization

Interactive Cards: Variable state highlighting

Interactive Elements:
Live Code Updates: See code change as variables update

Console Output: Real-time decision logging

Quick Simulations: One-click scenario testing

Challenge Builder: Write and test custom conditions

Business Context:
Real Scenarios: Msebetsi project evaluation

Professional Logic: Industry-standard decision making

Practical Examples: Budget, timeline, team management

Progressive Difficulty:
Basic: Single if statements

Intermediate: if-else chains, logical operators

Advanced: Nested conditionals, complex business rules

Expert: Custom condition writing, edge case handling

Teaching Tips:
Start with Visuals: Let students play with traffic lights first

Explain Concepts: Use the flow chart to teach decision flow

Hands-On Practice: Have students adjust variables and predict outcomes

Code Connection: Show how visual decisions translate to code

Challenge Extension: Encourage students to create their own conditions

This immersive, traffic control-themed lab makes learning conditional statements engaging and memorable while building practical skills for real-world Msebetsi development work!
