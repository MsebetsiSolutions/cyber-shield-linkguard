🔣 The Comparison Operators

==
Loose Equality

Compares values after type conversion

Use Case: Checking if user input (string "50000") matches budget (number 50000)

50000 == "50000" → true

===
Strict Equality

Compares values AND types (no conversion)

Use Case: Validating API responses where type matters

50000 === "50000" → false

!=
Loose Inequality

Not equal after type conversion

Use Case: Checking if discount doesn't apply (0 vs "0")

0 != "0" → false

!==
Strict Inequality

Not equal in value OR type

Use Case: Ensuring payment status isn't just falsy

0 !== "0" → true

>
Greater Than

First value is larger

Use Case: Checking if budget exceeds threshold

budget > 100000

<
Less Than

First value is smaller

Use Case: Checking if hours worked are under limit

hours < 40

>=
Greater or Equal

First value is larger or equal

Use Case: Minimum project budget requirements

budget >= 50000

<=
Less or Equal

First value is smaller or equal

Use Case: Maximum team size limits

teamSize <= 10

📊 Equality Comparison Truth Table

Comparison == (Loose) === (Strict) Msebetsi Example
5 == "5" true false User input "5" vs stored 5
0 == false true false Budget 0 vs not approved
null == undefined true false Missing vs unset data
"true" == true false false String "true" vs boolean
[] == false true false Empty task list vs no tasks

💡 Professional Tip: Always use === and !== in production code to avoid bugs!

// Client Budget Approval System
function approveProjectBudget(clientBudget, minBudget, maxBudget) {
  // Task 1: Check if budget meets minimum requirement
  if (clientBudget >= minBudget) {
    console.log(`✅ Budget approved: R${clientBudget} meets minimum of R${minBudget}`);
  } else {
    console.log(`❌ Budget too low: R${clientBudget} < R${minBudget}`);
  }

  // Task 2: Check if budget exceeds maximum (strict check)
  if (clientBudget === maxBudget) {
    console.log("⚠️ Budget at maximum limit");
  } else if (clientBudget <= maxBudget) {
    console.log("✅ Budget within limits");
  } else {
    console.log("❌ Budget exceeds maximum");
  }
}

// Test cases - Predict the outputs!
approveProjectBudget(75000, 50000, 100000);
approveProjectBudget("50000", 50000, 100000);
approveProjectBudget(0, 50000, 100000);

🎯 Key Takeaways

✅ Always Use Strict Comparisons

=== and !== prevent type coercion bugs

Example: 0 === false is false (correct)

✅ Understand Type Coercion

Loose comparisons convert types automatically

Example: "5" == 5 is true (string becomes number)

✅ Chain Comparisons Properly

Use logical operators (&&, ||) for multiple conditions

Example: budget >= 50000 && budget <= 200000
