🔍 PostgreSQL Debugging Toolkit

Professional database engineers use these tools to diagnose and fix issues.

Debugging Commands Essential PostgreSQL debugging tools 
-- 1. View table structure
\d table_name
\d+ table_name  -- Detailed view

-- 2. Check database connections
SELECT * FROM pg_stat_activity;

-- 3. View table constraints
SELECT conname, contype, convalidated 
FROM pg_constraint 
WHERE conrelid = 'table_name'::regclass;

-- 4. Check for locks
SELECT * FROM pg_locks 
WHERE relation = 'table_name'::regclass;

-- 5. View query plan (EXPLAIN)
EXPLAIN SELECT * FROM table_name;
EXPLAIN (ANALYZE, BUFFERS) SELECT * FROM table_name;

-- 6. Check table size
SELECT pg_size_pretty(pg_total_relation_size('table_name'));

-- 7. View active queries
SELECT pid, query, state, age(clock_timestamp(), query_start) 
FROM pg_stat_activity 
WHERE state != 'idle';

-- 8. Check for missing indexes
SELECT schemaname, tablename, attname, n_distinct
FROM pg_stats 
WHERE tablename = 'table_name';

🔧 Common PostgreSQL Errors & Solutions

🚨 Error: "column does not exist"

ERROR: column "column_name" does not exist

Solutions:

  • Check column name spelling
  • Use \d table_name to see columns
  • Check for case sensitivity (use quotes for mixed case)
  • Verify you're querying the right table

🚨 Error: "relation does not exist"

ERROR: relation "table_name" does not exist

Solutions:

  • Check table name spelling
  • Verify you're in the right database
  • Check schema (public vs other schemas)
  • Table might have been dropped

🚨 Error: "syntax error at or near"

ERROR: syntax error at or near "INSERT"

Solutions:

  • Check SQL syntax
  • Look for missing commas, parentheses
  • Verify keyword spelling
  • Check for unclosed quotes

🚨 Error: "duplicate key value violates unique constraint"

ERROR: duplicate key value violates unique constraint

Solutions:

  • Check for duplicate values in unique columns
  • Use ON CONFLICT clause for upserts
  • Delete duplicates before inserting
  • Use SERIAL for auto-incrementing IDs

📝 Complete ALTER TABLE Reference

1. Add New Columns

Adding columns to existing table 
-- Add single column
ALTER TABLE power_plant_data
ADD COLUMN energy_type VARCHAR(20);

-- Add multiple columns
ALTER TABLE power_plant_data
ADD COLUMN latitude DECIMAL(9,6),
ADD COLUMN longitude DECIMAL(9,6),
ADD COLUMN max_capacity DECIMAL(10,2);

-- Add column with default value
ALTER TABLE power_plant_data
ADD COLUMN is_active BOOLEAN DEFAULT true;

-- Add column with NOT NULL constraint
ALTER TABLE power_plant_data
ADD COLUMN country VARCHAR(50) NOT NULL DEFAULT 'South Africa';

2. Modify Existing Columns

Changing column properties 
-- Change data type
ALTER TABLE power_plant_data
ALTER COLUMN plant_name TYPE VARCHAR(150);

-- Set DEFAULT value
ALTER TABLE power_plant_data
ALTER COLUMN status SET DEFAULT 'operational';

-- Drop DEFAULT value
ALTER TABLE power_plant_data
ALTER COLUMN status DROP DEFAULT;

-- Add NOT NULL constraint
ALTER TABLE power_plant_data
ALTER COLUMN plant_name SET NOT NULL;

-- Remove NOT NULL constraint
ALTER TABLE power_plant_data
ALTER COLUMN plant_name DROP NOT NULL;

3. Rename Columns & Tables

Renaming database objects 
-- Rename column
ALTER TABLE power_plant_data
RENAME COLUMN mw TO output_megawatts;

-- Rename table
ALTER TABLE power_plant_data
RENAME TO power_plants;

-- Rename constraint
ALTER TABLE power_plants
RENAME CONSTRAINT power_plant_data_pkey TO power_plants_pkey;

4. Drop Columns & Constraints

Removing elements safely 
-- Drop column (if empty or with CASCADE)
ALTER TABLE power_plants
DROP COLUMN old_column_name;

-- Drop column with CASCADE (drops depending objects)
ALTER TABLE power_plants
DROP COLUMN old_column CASCADE;

-- Drop constraint
ALTER TABLE power_plants
DROP CONSTRAINT constraint_name;

-- Drop multiple columns
ALTER TABLE power_plants
DROP COLUMN column1,
DROP COLUMN column2;

5. Add Constraints to Existing Tables

Adding constraints after table creation 
-- Add PRIMARY KEY (if not already set)
ALTER TABLE power_plants
ADD PRIMARY KEY (plant_id);

-- Add FOREIGN KEY
ALTER TABLE maintenance_logs
ADD CONSTRAINT fk_plant
FOREIGN KEY (plant_id) REFERENCES power_plants(plant_id);

-- Add UNIQUE constraint
ALTER TABLE power_plants
ADD CONSTRAINT unique_plant_name UNIQUE (plant_name);

-- Add CHECK constraint
ALTER TABLE power_plants
ADD CONSTRAINT check_output_positive
CHECK (output_megawatts >= 0);

-- Add multiple constraints
ALTER TABLE power_plants
ADD CONSTRAINT check_capacity 
CHECK (output_megawatts <= max_capacity),
ADD CONSTRAINT valid_energy_type
CHECK (energy_type IN ('solar', 'wind', 'hydro', 'geothermal'));
