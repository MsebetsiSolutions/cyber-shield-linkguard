Interactive Lab Workflow

1

Understand the Task & Key Commands

Review the essential PostgreSQL commands you'll need:

-- 1. List all databases (psql meta-command) \l -- 2. Drop/Delete an existing database DROP DATABASE IF EXISTS sample_db; -- 3. Create a new database CREATE DATABASE books_db; -- 4. Connect to/Select a database (psql meta-command) \c books_db -- Alternative: Connect via initial login -- psql -d books_db

\l: Meta-command to list all databases in your PostgreSQL cluster[citation:1].

DROP DATABASE: Permanently removes a database and all its contents. Use IF EXISTS to avoid errors.

CREATE DATABASE: Creates a new, empty database with the specified name.

\c: Meta-command to connect your psql session to a different database.

2

Create Your schema.sql File

Using a text editor (VS Code, Sublime, Notepad++), create a file named schema.sql with the following structure:

-- ============================================ -- schema.sql -- Purpose: Drop sample_db and create books_db -- Author: [Your Name] -- ============================================ -- 1. Drop the sample_db if it exists DROP DATABASE IF EXISTS sample_db; -- 2. Create the new books_db database CREATE DATABASE books_db; -- 3. Comment: The connection command is typically -- executed in the psql shell, not in the SQL file. -- To connect: \c books_db

Save this file to a known location on your computer (e.g., Desktop or project folder).

3

Test Your Script (Optional)
