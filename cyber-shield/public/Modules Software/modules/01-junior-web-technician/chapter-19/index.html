6 Positioning Methods Pixel-Perfect Control Performance Optimized

Static Positioning

Default positioning in normal document flow. Cannot be moved with top/right/bottom/left.

Static
position: static;
/* Default - follows normal flow */

Relative Positioning

Positioned relative to its normal position. Space is reserved in normal flow.

Relative
position: relative;
top: 20px;
left: 20px;
/* Offset from original position */

Absolute Positioning

Removed from normal flow. Positioned relative to nearest positioned ancestor.

Absolute
⚡
position: absolute;
top: 20px;
right: 20px;
/* Parent must be positioned */

Fixed Positioning

Positioned relative to viewport. Stays in place during scrolling.

Fixed
position: fixed;
bottom: 30px;
right: 30px;
/* Relative to viewport */

Z-Index Stacking

Controls vertical stacking order. Higher values appear on top.

z: 1
z: 2
z: 3
z-index: 3;
/* Higher values appear on top */
/* Only works on positioned elements */

CSS Transform

Move, rotate, scale elements without affecting document flow.

Transform
transform: translate(20px, -20px) rotate(15deg) scale(1.2);
/* GPU accelerated - high performance */
