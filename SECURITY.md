# Security Policy

## Supported Versions
The following table shows which versions of **Cyber Shield LinkGuard** are currently supported with security updates and patches:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.9.x   | :white_check_mark: |
| < 0.9   | :x:                |

⚠️ Note: Only the latest stable release and the previous minor version receive security patches. Older versions are considered **end-of-life (EOL)** and will not be patched.

---

## Reporting a Vulnerability

We take security issues seriously. If you discover a vulnerability in **Cyber Shield LinkGuard**, please follow the steps below:

1. **Do not open a public issue.**  
   Instead, report vulnerabilities responsibly via email or private channels.

2. **Contact us at:**  
   📧 **security@msebetsi-solutions.com**

3. **Provide as much detail as possible**, including:
   - Steps to reproduce the issue
   - Potential impact
   - A proof-of-concept (if available)
   - Affected version(s)

4. **Our Response Process**:
   - We will acknowledge receipt of the report within **48 hours**.
   - We will provide a status update within **5 business days**.
   - If the vulnerability is confirmed, we will work on a fix and release a patch as soon as possible.
   - You will be credited for the discovery (unless you prefer anonymity).

---

## Responsible Disclosure

- Please avoid testing vulnerabilities on production deployments without prior approval.  
- Do not exploit a vulnerability for personal gain or malicious purposes.  
- Public disclosure of vulnerabilities should only happen **after a fix is released** and with our agreement.
